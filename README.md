# PDF Merger

複数の PDF を **ブラウザだけで** ひとつに結合するシンプルなツールです。
ファイルはサーバーに送信されず、すべて端末内 (JavaScript) で処理されます。

## 特長

- インストール不要(ブラウザを開くだけ)
- PDF はアップロードされない(プライバシー安全)
- ドラッグ & ドロップで並び替え
- **各 PDF ごとにページを選択/削除できる**(ページ指定欄)
- **全ページの横幅を揃えられる**(縦横比は維持。基準幅は 最大幅 / 最小幅 / A4縦 から選択)
- 出力ファイル名を指定可能
- 静的ファイルのみ → **GitHub Pages で無料公開可能**

## ページ指定の書き方

各ファイルの「ページ」欄に書きます(1始まり):

| 入力     | 意味                                  |
| -------- | ------------------------------------- |
| 空欄     | 全ページ                              |
| `1-3,5`  | 1〜3ページ目と5ページ目のみ           |
| `-4`     | 4ページ目を**削除**(他は全部残す)    |
| `-4,-6`  | 4ページ目と6ページ目を削除            |
| `-2-5`   | 2〜5ページ目をまとめて削除            |
| `3,1,2`  | 順番を入れ替えて結合(3→1→2の順)     |

※ 1ファイル内で「含める」と「除外(`-`付き)」の混在はできません。

## ローカルで試す

特別なビルドは不要です。`index.html` をブラウザで直接開いても動きますが、
ローカルサーバーで開くのが確実です:

```bash
# Python があれば
python -m http.server 8000
# → http://localhost:8000 を開く
```
